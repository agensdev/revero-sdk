# Security policy

Do not open a public issue for a suspected vulnerability or include client
credentials, access tokens, webhook secrets, meeting content or presigned
upload URLs in an issue.

Use GitHub's private vulnerability reporting for
[`agensdev/revero-sdk`](https://github.com/agensdev/revero-sdk/security/advisories/new).
Include affected package versions, impact and a minimal reproduction with all
credentials and customer data removed.
